# 問題生成 追加ルール（ITパスポート以降の全資格に適用）

さくらさん指示（2026-08-17）。**問題を生成・修正する際は必ず守ること。**

> **適用範囲**：当初は基本情報（FE）向けの指示だったが、2026-08-17に
> **ITパスポート以降に取得する全資格へ適用**することが決まった。
> **CLF-C02は合格済みのため対象外**（既存の問題は修正しない）。
> 新しい資格のアプリを作るときも、最初からこのルールに沿って作問する。

---

## 1. 視覚要素の強制

- 生成する問題セットのうち、**最低20%**は図・表・フローチャート・ER図・UML図
  （クラス図／シーケンス図）・ネットワーク構成図のいずれかを**本質的に必要とする**問題にする
- 図が必要な問題は、テキストで説明せず、**SVGで実際に図を生成して問題に組み込む**
- 「図を見て答える」形式を避けて文章だけで完結させることは**禁止**

**実装**：問題オブジェクトの `fig` フィールドにインラインSVG文字列を入れる。
`_engine/engine.js` の `qFigure()` が設問文の下に描画する（過去問・シナリオ・科目B共通）。
SVGは `currentColor` とカラートークン（`var(--orange)` 等）だけで描き、
ダークテーマで見えなくならないようにすること。

## 2. 計算問題の数値バリエーション

- 2進数変換、稼働率計算、待ち行列理論、原価計算などは、**毎回異なる数値セット**を使う
- 同一の数値パターン・同一の計算結果になる問題を重複生成しない

## 3. 科目Bの擬似言語仕様

- **IPA公式の擬似言語表記法に厳密に従う**（一般的なプログラミング言語風に寄せない）
- 仕様は **`certs/fe/擬似言語仕様_IPA公式.md`** に一次情報から転記済み。**これを唯一の正とする**
- 不明な場合は書式を断定せず、同ファイル冒頭の公式PDFを再取得して確認してから生成する

**特に間違えやすい点**
- 代入は `←`、比較は `＝`（`==` ではない）、不等号は `≠` `≦` `≧`（全角）
- 剰余は `mod`、乗除は `×` `÷`
- `for (i を 1 から n まで 1 ずつ増やす)` という日本語の制御記述
- **配列の要素番号は 1 から始まる**。配列を扱う問題は問題文に必ずその旨を明記する
- 手続・関数の宣言は行頭に `○`

## 4. 難易度分布の維持

- 大量生成するとき、**後半になるほど易化する傾向を避ける**
- 易問・中問・難問を本番の分布比率に近い形で維持する（**体感目安：易3割・中5割・難2割**）

**実装**：問題オブジェクトの `d` フィールドに `1`（易）／`2`（中）／`3`（難）を持たせ、
チャンクごとに分布を数えて検証する。

## 5. 出題分野のバランス

- テクノロジ系・マネジメント系・ストラテジ系の比率を実際の試験に近づける
  （科目A：**テクノロジ系41問／マネジメント系7問／ストラテジ系12問**）
- **ネットワーク・セキュリティに偏らせない**。経営戦略・法務・会計・
  プロジェクトマネジメント・開発プロセスなど手薄になりがちな分野も均等に含める

## 6. 誤答選択肢の質

- 誤答選択肢は「明らかに違う」レベルの雑な引っ掛けにしない
- **正答と紛らわしい、もっともらしい内容**にする。よく読まないと選んでしまう精度を意識する

## 7. 解説の質

- 正答の理由だけでなく、**各誤答選択肢がなぜ誤りなのか**も解説に含める
- 「なぜその答えか」と「なぜ他の選択肢ではないか」の**両方を必ず記載**する

## 8. 出題形式

- **科目Aと科目Bを明確に分けて生成する**
- 科目Aは4択形式（`QQ`）、科目Bは擬似言語＋設問形式（`PSEUDO_Q`）とし、
  科目BはIPA公式の出題形式に準拠する

## 検証スクリプト

**`certs/_tools/validate-content.js` が上記8ルールを機械的に検証する。**
問題を追加・修正したら必ず実行し、全項目OKにしてからコミットすること。

```bash
cd certs
node _tools/validate-content.js itpass   # ITパスポート
node _tools/validate-content.js fe       # 基本情報
node _tools/validate-content.js          # 対象資格をまとめて
```

検証する内容：

- カードID・問題IDの重複／欠番（**IDは学習記録の紐づけキー。振り直し厳禁**）
- カテゴリIDの対応（`FC_CATS_DEF` ⇔ `QCAT` ⇔ 各問題の `c`）と処方箋の網羅性
- 正解 index が選択肢の範囲内
- **図つき問題の割合が20%以上**（ルール1）
- **同一カテゴリで同じ数値パターンの計算問題が無い**（ルール2）
- **擬似言語に半角の `<=` `>=` `!=` `==` `&&` が混入していない**（ルール3）
- **難易度分布が 易3:中5:難2 におおむね沿っている**（ルール4／各±12ポイント）
- **分野バランスが公式比率に近い**（ルール5）
- **正解だけが極端に長い問題が無い**（ルール6／読まずに当てられる作問ミスの検出）
- **解説が各誤答を具体的に引用して説明している**（ルール7）

### 新しい資格を足すときは

`_tools/validate-content.js` の `CERT_PROFILE` に1件追加する（分野の分け方と
公式の出題比率を記述する）。AWS資格のように3分野の枠組みが無い場合は
`fields:null` にすると分野バランスの検証だけを飛ばせる。
