## 1. 記述形式

| 記述形式 | 説明 |
|---|---|
| `○手続名又は関数名` | 手続又は関数を宣言する |
| `型名: 変数名` | 変数を宣言する |
| `/* 注釈 */` または `// 注釈` | 注釈を記述する |
| `変数名 ← 式` | 変数に式の値を代入する |
| `手続名又は関数名(引数, …)` | 手続又は関数を呼び出し、引数を受け渡す |

### 選択処理

```
if (条件式1)
  処理1
elseif (条件式2)
  処理2
else
  処理3
endif
```

条件式を上から評価し、最初に真になった条件式に対応する処理を実行する。
以降の条件式は評価せず、対応する処理も実行しない。
`elseif` と処理の組みは複数記述することも省略することもある。
`else` と処理の組みは一つだけ記述し、省略することもある。

### 繰返し処理

```
while (条件式)        ← 前判定繰返し
  処理
endwhile

do                    ← 後判定繰返し
  処理
while (条件式)

for (制御記述)        ← 繰返し
  処理
endfor
```

**`for` の制御記述の書式（公式サンプルの実例）**

```
for (i を 1 から n まで 1 ずつ増やす)
for (i を 2 から inの要素数 まで 1 ずつ増やす)
for (i を utf8Bytesの要素数 から 1 まで 1 ずつ減らす)
```

## 2. 演算子と優先順位

| 種類 | 演算子 | 優先度 |
|---|---|---|
| 式 | `()` `.` | 高 |
| 単項演算子 | `not` `＋` `－` | ↑ |
| 二項演算子（乗除） | `mod` `×` `÷` | ↑ |
| 二項演算子（加減） | `＋` `－` | ↑ |
| 関係 | `≠` `≦` `≧` `＜` `＝` `＞` | ↓ |
| 論理積 | `and` | ↓ |
| 論理和 | `or` | 低 |

- 演算子 `.` は、メンバ変数又はメソッドのアクセスを表す
- 演算子 `mod` は、剰余算を表す
- **記号は全角**（`←` `＋` `－` `×` `÷` `≠` `≦` `≧` `＜` `＝` `＞`）。
  半角の `<=` `>=` `!=` `+` `-` `*` `/` を使わないこと

## 4. 配列

- 要素は `[` と `]` の間に**要素番号**を指定してアクセスする
- **要素番号は 1 から始まる**（問題文にも「配列の要素番号は 1 から始まる」と明記される）
- 二次元配列の要素番号は、**行番号, 列番号**の順に `,` で区切って指定する
- `{` は配列の内容の始まり、`}` は終わりを表す
- 二次元配列で内側の `{` `}` に囲まれた部分は 1 行分の内容を表す

**公式サンプルでの慣用表現**

```
整数型の配列: out ← {}                 // 要素数0の配列
整数型の配列: bins ← {n個の未定義の値}
整数型: n ← dataの要素数
outの末尾 に in[1]の値 を追加する
```

## 5. 未定義

変数に値が格納されていない状態を **“未定義”** という。
変数に **“未定義の値”** を代入すると、その変数は未定義になる。

## 6. 出題形式（公式サンプルより）

- **穴埋め1個**：「次の記述中の [ a ] に入れる正しい答えを、解答群の中から選べ」
- **穴埋め複数（組合せ）**：「次のプログラム中の [ a ]〜[ c ] に入れる正しい答えの
  組合せを、解答群の中から選べ」→ 解答群は a/b/c の組を並べた表形式
- **トレース**：「プログラムを実行すると、“[ ]”と出力される」
- 配列を扱う問題では、問題文の冒頭に必ず
  **「ここで、配列の要素番号は 1 から始まる。」**と明記される
- 解答群の記号は **ア・イ・ウ・エ・オ・カ・キ**（選択肢が5個や7個のこともある）
